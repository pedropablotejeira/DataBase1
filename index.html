Introducción

El presente portafolio de evidencias de la asignatura Base de Datos I recopila el compendio de conocimientos teóricos y prácticos desarrollados a lo largo del cuatrimestre por el grupo D-CS-2-1 del Instituto Técnico Superior Especializado (ITSE). Su propósito central es documentar de manera estructurada el proceso de aprendizaje en el diseño, gestión y explotación de sistemas de Bases de Datos.

A lo largo de los ocho módulos que componen este compendio, se abordan desde los fundamentos de la arquitectura de los Sistemas de Gestión de Bases de Datos (SGBD) y el modelado conceptual mediante Diagramas Entidad-Relación (DER), hasta la normalización de tablas y la aplicación práctica de instrucciones en Lenguaje de Definición y Manipulación de Datos (DDL y DML) en SQL. Este recorrido refleja el esfuerzo colaborativo del equipo para garantizar la integridad, seguridad y eficiencia en el tratamiento de la información.

Conclusiones

El desarrollo de este portafolio permitió consolidar de forma integral los conceptos fundamentales en la administración y estructuración de bases de datos relacionales. Se comprobó que una fase de diseño conceptual rigurosa —basada en el correcto levantamiento de entidades, atributos y cardinalidades— es indispensable para prevenir anomalías y redundancias críticas en el almacenamiento de los datos.

Asimismo, la implementación técnica mediante sentencias SQL (DDL, DML y consultas multitabla con operadores JOIN) otorgó al grupo la capacidad operativa para transformar esquemas teóricos en bases de datos funcionales, seguras y optimizadas. La ejecución de este proyecto integrador reafirma que los sistemas de bases de datos constituyen el núcleo operativo fundamental sobre el cual se edifican todas las soluciones tecnológicas e informáticas modernas.

Portafolio de Base de Datos I

Grupo D-CS-2-1 | Compendio de Modelado, Diagramas Entidad-Relación, Normalización y Lenguaje MySQL

Módulo 01

Fundamentos y Arquitectura de Sistemas de Bases de Datos

Introducción a los conceptos clave de bases de datos. Comparativa entre la gestión tradicional de archivos y los Sistemas de Gestión de Bases de Datos (SGBD/DBMS). Estudio de la arquitectura ANSI/SPARC de tres niveles (Externo, Conceptual e Interno) e independencia de datos.

Módulo 02

Modelado de Datos Conceptual (Diagrama Entidad-Relación)

Diseño conceptual de bases de datos mediante el Modelo Entidad-Relación (DER). Definición de entidades, atributos (simples, compuestos, multivaluados), relaciones y tipos de cardinalidad (1:1, 1:N, N:M). Identificación de Claves Primarias (PK) y Claves Foráneas (FK).

Módulo 03

El Modelo Relacional y Reglas de Normalización

Mapeo del modelo conceptual a esquemas relacionales. Estudio de las reglas de integridad de dominio, de entidad y referencial. Aplicación técnica del proceso de Normalización (Primera, Segunda y Tercera Forma Normal - 1FN, 2FN, 3FN) para eliminar redundancias y anomalías.

Módulo 04

Lenguaje SQL: Lenguaje de Definición de Datos (DDL)

Creación e implementación práctica de la estructura de la base de datos en un SGBD (MySQL / PostgreSQL / SQL Server). Uso de sentencias DDL: `CREATE DATABASE`, `CREATE TABLE`, `ALTER TABLE` y `DROP TABLE`. Definición de tipos de datos y restricciones (`NOT NULL`, `UNIQUE`, `CHECK`, `FOREIGN KEY`).

Módulo 05

Lenguaje SQL: Manipulación de Datos y Consultas (DML)

Poblado y gestión de datos con sentencias `INSERT`, `UPDATE` y `DELETE`. Dominio de consultas de datos complejas mediante `SELECT`, filtrado con `WHERE`, ordenamiento con `ORDER BY`, funciones de agregación (`COUNT`, `SUM`, `AVG`), cláusulas `GROUP BY` / `HAVING` y uniones entre tablas (`INNER JOIN`, `LEFT JOIN`).

Módulo 06

Proyecto Integrador e Implementación Final

Desarrollo completo de un caso de negocio real. Desde el análisis de requerimientos, levantamiento del DER, normalización de tablas, ejecución del script DDL/DML, hasta la generación de respaldos (`.sql`) e informes de rendimiento.

Conclusión de la Asignatura:

El dominio de las Bases de Datos Relacionales constituye el pilar fundamental para el desarrollo de sistemas de información robustos, garantizando la integridad, seguridad y disponibilidad eficiente de los datos empresariales.
